# web-scroll-efect (Claude Code skill)

Scroll-scrubbed frame-sequence animace v hero sekci (Apple styl) — jak scrolluješ,
přehrává se sekvence obrázků kreslená na `<canvas>` podle pozice scrollu.

## Instalace
Zkopíruj složku `web-scroll-efect/` do svých Claude Code skillů:

- Windows: `%USERPROFILE%\.claude\skills\web-scroll-efect\`
- macOS/Linux: `~/.claude/skills/web-scroll-efect/`

Pak ve skillu najdeš celý postup v `SKILL.md` (Next.js Hero.tsx scrubber + Lottie intro).
